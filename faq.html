Vanliga frågor och svar

Hitta svar på vanliga frågor om pillpris.se

Vad är pillpris.se? expand_more
Pillpris.se visar de priser som varje månad publiceras av Tandvård- och läkemedelsförmånsverket (TLV) för de läkemedel som upphandlas inom systemet för Perioden Vara. Genom att visa priserna på ett tydligt sätt kan du jämföra olika alternativ och se prishistorik för att planera dina inköp och spara pengar.
Vad betyder "Periodens Vara"? expand_more
Varje månad får läkemedelstillverkare tävla om vem som kan erbjuda det lägsta priset för vissa läkemedel. Det företag som kan garantera ett rikstäckande utbud för nästkommande månad, till det billigaste priset, utses till "Periodens vara". Du kan läsa mer på TLVs hemsida: https://www.tlv.se/apotek/generiskt-utbyte/periodens-varor.html
Hur kan jag spara pengar med pillpris.se? expand_more
Eftersom nya upphandlingar sker varje månad så kan priserna på läkemedel variera. Genom att jämföra priserna på pillpris.se kan du se om månadens pris är historiskt högt eller historiskt lågt. Om du har möjlighet att vänta med ditt köp kan du spara pengar genom att köpa läkemedlet när priset är lägre. Du kan också jämföra olika alternativ och se om det finns billigare alternativ som är utbytbara.
Varför är ett läkemedel billigare än Periodens Vara? expand_more
Ibland vinner inte det företag som kan erbjuda det lägsta priset, utan istället det företag som kan garantera ett rikstäckande utbud. Det betyder att det kan finnas billigare alternativ än Periodens Vara, men de är inte alltid tillgängliga på alla apotek.
Vad betyder det att en vara är Restnoterad? expand_more
Om ett företag drabbas av ett längre produktionsstopp eller problem med distributionen kan det leda till att läkemedlet inte längre kan levereras till apoteken. Dessa scenario kallas för en restnotering. Om flera företag drabbas av restnoteringar kan det betyda att priset på läkemedelet blir högre än normalt. Det kan även betyda att läkemedlet blir svårare att få tag på.
Vad är R1 och R2 (reserv)? expand_more
I de fall som ett apotek har sålt slut på periodens vara, erbjuds reservalternativ, benämnda som R1 och R2. Detta för att säkerställa god tillgång på läkemedel även när Periodens vara har sålt slut. Du som konsument kan besöka ett annat apotek och se ifall de erbjuder Periodens vara istället, och på så sätt spara pengar.
Hur vet jag när det är bäst att köpa ett läkemedel? expand_more
Ungefär den 15:e varje månad så publiceras nästkommande månads preliminära priser. Genom att jämföra historiska priser med det nuvarande och kommande priset, kan du bestämma om du vill köpa läkemedelet nu, eller vänta till nästa månad.
Varför kan jag inte hitta mitt läkemedel? expand_more
Alla läkemedel upphandlas inte med systemet för periodens vara. pillpris.se visar bara de läkemedel som upphandlas på detta sätt. Om du inte kan hitta ditt läkemedel kan det bero på att det inte är utbytbart eller inte ingår i"Periodens Vara"-systemet.
Hur ofta uppdateras priserna? expand_more
Priserna hämtas varje natt från TLV:s prisdatabas. Upphandlingen sker i regel varje månad.
Varför har priset ändrats under månadens gång? expand_more
Om ett företag inte längre kan tillhandahålla varan för innevarande period, så kan TLV besluta att byta ut periodens vara mot ett annat alternativ. Detta kan leda till att priset ändras under månadens gång.
Vem står bakom pillpris.se? expand_more
Pillpris.se är utvecklat av Pontus Cedrell. Hemsidan är egenutvecklad och är inte kopplad till TLV eller något läkemedelsföretag och drivs utan vinstintresse. Om du har frågor eller vill komma i kontakt med utvecklaren kan du göra det här.
